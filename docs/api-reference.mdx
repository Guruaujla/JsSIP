## `class VoiceSDK`

The main entry point for the library.

### Constructor

```typescript
new VoiceSDK(options: VoiceSDKOptions)
```

#### `VoiceSDKOptions`

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `token` | `string` | Yes | The organizational token for authentication. |
| `authServer` | `string` | Yes | The URL of the backend service to exchange the token for SIP credentials. The SDK appends `/sip-credentials` to this URL. |
| `ice` | `IceOptions` | No | ICE configuration (STUN/TURN). |
| `media` | `MediaOptions` | No | Media constraints and device selection. |
| `sounds` | `{ ringtoneUrl?: string }` | No | Configuration for ringtone audio. |
| `logging` | `'none' \| 'error' \| 'info' \| 'debug'` | No | Logging verbosity level. |
| `sip` | `SipOptions` | No | Advanced SIP configuration (userAgent, keepAlive, etc). |
| `erp` | `ErpOptions` | No | Configuration for ERP/CRM integration hooks. |

**Interface Definitions:**

```typescript
interface IceOptions {
  stun?: string[];
  turn?: { urls: string[]; username: string; credential: string }[];
  trickle?: boolean;
}

interface MediaOptions {
  audioInputId?: string;
  outputDeviceId?: string;
  constraints?: MediaTrackConstraints;
}

interface SipOptions {
  displayName?: string;
  userAgentString?: string;
  registerExpiresSec?: number;
  keepAliveIntervalSec?: number;
  outboundProxy?: string;
  registrar?: string;
}

interface ErpOptions {
  apiUrl: string;
  queryParam?: string; // default 'phone'
  token?: string;
  headers?: Record<string, string>;
}
```

### Methods

#### `init()`

```typescript
async init(): Promise<void>
```

Initializes the SDK, performs leader election, fetches credentials, and connects to the SIP server.
*   **Returns**: Promise that resolves when connected (or leader election settles).
*   **Throws**: `SDKError` if authentication fails.

**Note on Leader Election:**
The SDK uses `BroadcastChannel` to coordinate between tabs. Only one tab (the "leader") will maintain the active SIP registration. If `init()` is called in multiple tabs, only the leader will connect. If the leader tab is closed, a follower will promote itself and connect.

#### `call()`

```typescript
async call(options: CallOptions): Promise<CallSession>
```

Initiates an outbound call.

**Parameters:**

| Name | Type | Description |
| :--- | :--- | :--- |
| `options.target` | `string` | The destination number or SIP URI. |
| `options.extraHeaders` | `string[]` | (Optional) Custom SIP headers. |
| `options.withEarlyMedia` | `boolean` | (Optional) Enable early media. |
| `options.dtmfMode` | `'RFC2833' \| 'SIP_INFO'` | (Optional) DTMF mode. |

*   **Returns**: `Promise<CallSession>`
*   **Throws**: Error if SDK is not initialized or network is unavailable.

#### `getActiveSessions()`

```typescript
getActiveSessions(): CallSession[]
```

Returns an array of currently active `CallSession` objects.

#### `on()`

```typescript
on(event: string, handler: Function): () => void
```

Subscribe to SDK events. Returns an unsubscribe function.

### Events (`VoiceSDKEvents`)

| Event | Payload | Description |
| :--- | :--- | :--- |
| `ready` | `void` | Fired when the SDK is ready. |
| `connectionChanged` | `{ state: 'connecting' \| 'connected' \| 'disconnected' \| 'reconnecting' }` | Fired when WebSocket/SIP connection state changes. |
| `registrationChanged` | `{ state: 'registered' \| 'unregistered' \| 'failed', reason?: string }` | Fired when SIP registration status changes. |
| `incomingCall` | `{ session: CallSession, from: string, displayName?: string, data?: any }` | Fired when a new call is received. |
| `callUpdated` | `{ session: CallSession, state: CallState, reason?: string }` | Fired when a call's state changes. |
| `callSummary` | `CallSummary` | Fired after a call ends. |
| `deviceChanged` | `{ microphones: MediaDeviceInfo[], speakers: MediaDeviceInfo[] }` | Fired when audio devices change. |
| `error` | `{ code: string, message: string, cause?: unknown }` | Fired on global errors. |

## `interface CallSession`

Represents an individual phone call.

### Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | Unique identifier for the call. |
| `direction` | `'inbound' \| 'outbound'` | Direction of the call. |
| `state` | `CallState` | Current state (`new`, `ringing`, `established`, `held`, `muted`, `ended`, `failed`). |

### Methods

#### `answer()`

```typescript
async answer(options?: { audio?: boolean }): Promise<void>
```
Answers an incoming call.

#### `hangup()`

```typescript
async hangup(): Promise<void>
```
Ends the call.

#### `hold()` / `resume()`

```typescript
async hold(): Promise<void>
async resume(): Promise<void>
```
Places the call on hold or resumes it.

#### `mute()` / `unmute()`

```typescript
async mute(): Promise<void>
async unmute(): Promise<void>
```
Toggles the local microphone audio.

#### `sendDTMF()`

```typescript
async sendDTMF(tone: string): Promise<void>
```
Sends a DTMF tone (0-9, *, #) to the remote peer.

#### `transfer()`

```typescript
async transfer(target: string): Promise<void>
```
Blind transfers the call to a new target.

#### `getSummary()`

```typescript
getSummary(): CallSummary
```
Returns the summary of the call.

---

## `interface CallSummary`

The payload for the `callSummary` event. Useful for ERP/CRM logging.

| Property | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | Call ID. |
| `direction` | `'inbound' \| 'outbound'` | Direction. |
| `from` | `string` | Caller URI. |
| `to` | `string` | Callee URI. |
| `startTime` | `number` | Unix timestamp of call start. |
| `answerTime` | `number` | Unix timestamp of answer (optional). |
| `endTime` | `number` | Unix timestamp of call end (optional). |
| `duration` | `number` | Duration in seconds (talk time). |
| `result` | `'Answered' \| 'Missed' \| 'Rejected' \| 'Failed' \| 'Busy'` | Final outcome of the call. |
